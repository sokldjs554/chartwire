이 페이지에서만 ChartWire의 백엔드 깊이를 보여줍니다.

Engineering deep dive

Realtime delivery

seq / ack / credit / resume / epoch로 WebSocket 재연결과 재전송을 다룹니다. ACK는 PostgreSQL durable commit 이후에만 증가합니다.

449 msack p95
0 / 0loss / dup

Tenant isolation

PostgreSQL RLS와 단일 app role을 사용해 테넌트 경계를 DB 수준에서도 강제합니다. 라우트 × 역할 × 테넌트 매트릭스 테스트를 둡니다.

RLSPostgreSQL
NOBYPASSRLSapp role

Outbox & recovery

Transactional outbox → Redis Streams → worker 흐름으로 비동기 이벤트 전달과 재시도를 다룹니다.

413 ev/s100K outbox
0DLQ

Consent & purge

세션 데이터는 crypto-shred 대상으로, 보존이 필요한 서명 기록은 별도 retention 경계로 관리합니다.
